How to use XML Formatter

  1. Paste your minified or messy XML into the input box.
  2. Click Format XML to indent and re-structure it with consistent 2-space nesting.
  3. Copy the formatted output.

Frequently Asked Questions

What happens if my XML is malformed?

The formatter validates the document first (using the browser's built-in XML parser) and shows a "could not parse" message if it isn't well-formed, rather than guessing at a layout.

Does it validate against a schema (XSD/DTD)?

No — it checks that the XML is well-formed (correctly nested and closed tags), not that it matches a specific schema.

Is my code or data sent to a server?

No. Formatting runs entirely client-side in your browser, so nothing you paste in is uploaded or logged.

Does it work on mobile?

Yes, it works in any modern mobile or desktop browser.
