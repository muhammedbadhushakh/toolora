DNS Propagation Checker

Compare a domain's DNS answer across several major public resolvers to see if a recent change has propagated.

Querying public resolvers…

This queries several major public DNS resolvers directly over DNS-over-HTTPS (Google, Cloudflare, Quad9, AdGuard and OpenDNS). Browsers can't query arbitrary global nameservers the way command-line tools can, so results reflect what each provider's resolver currently has cached — a good practical signal for propagation, even if it's not literally probing every country.

How to use DNS Propagation Checker

  1. Enter the domain name you recently changed a DNS record for.
  2. Click check to query several major public resolvers at once.
  3. Compare the answers each resolver returns to see whether your change has propagated everywhere.

Frequently Asked Questions

Which resolvers does it check?

Google Public DNS, Cloudflare, Quad9, AdGuard and OpenDNS, queried directly over DNS-over-HTTPS.

Does matching answers across all resolvers mean it's "fully propagated"?

It's a good practical signal — if all five major resolvers agree, most visitors worldwide will see the new record — but it isn't a guarantee for literally every resolver on earth, since some networks run their own private DNS caches.

Why do resolvers sometimes show different answers?

Each resolver caches records independently based on the record's TTL (time-to-live), so one may still be serving an old cached value while another has already picked up the change.

Does it work on mobile?

Yes, it works on any modern desktop or mobile browser.
