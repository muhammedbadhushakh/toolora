How to use DNS Lookup

  1. Enter a domain name (e.g. example.com).
  2. Choose the record type you want — A, AAAA, CNAME, MX, TXT, NS, SOA, CAA, SRV, or ANY.
  3. Click Lookup to query the record and see the results.

Frequently Asked Questions

Which DNS record types can I query?

A, AAAA, CNAME, MX, TXT, NS, SOA, CAA, SRV, and ANY — covering the record types most people need for troubleshooting email, hosting and domain setup.

Which resolver does this use?

Google's public DNS-over-HTTPS resolver (dns.google), so results reflect what Google's DNS servers currently have cached for the domain.

Why might my result differ from what I set in my DNS provider?

DNS changes take time to propagate, and different resolvers around the world can be caching different (older or newer) values until the record's TTL expires everywhere.

Does it work on mobile?

Yes, it works on any modern desktop or mobile browser.
