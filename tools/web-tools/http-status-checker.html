How to use HTTP Status Checker

  1. Enter the full URL you want to check (including https://).
  2. Click check to request the page.
  3. Review the status code, content type and response time returned.

Frequently Asked Questions

What does the status code tell me?

Codes in the 200s mean success, 300s mean redirects, 400s mean a client-side problem (like a 404 Not Found), and 500s mean a server error — this tool shows the code along with its plain-English meaning.

Why might a check fail even though the site loads in my browser?

The check is made through a public CORS proxy rather than directly from your machine, so sites that block proxy or bot-like traffic may occasionally return an error here even though they load normally for you.

Does it follow redirects?

It reports the status of the URL you enter — if that URL redirects, you'll see the redirect status code (3xx) rather than the final destination's code.

Does it work on mobile?

Yes, it works on any modern desktop or mobile browser.
