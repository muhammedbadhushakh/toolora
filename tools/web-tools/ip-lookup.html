How to use IP Lookup

  1. Enter any IPv4 or IPv6 address — or leave the field blank to look up your own.
  2. Click Lookup.
  3. Review the location, ISP and network details returned.

Frequently Asked Questions

How accurate is the location data?

IP geolocation is generally accurate to the city or region level, based on how the IP block is registered — it isn't a precise street address and can occasionally point to an ISP's regional hub rather than the user's exact location.

What happens if I leave the field blank?

The tool looks up whatever public IP address your own connection is currently using.

Where does the data come from?

A free public IP geolocation API (ipwho.is) — no API key or sign-up is required on your end.

Does it work on mobile?

Yes, it works on any modern desktop or mobile browser.
