How to use Split PDF

  1. Click the upload area and choose your file, or drag and drop it in.
  2. Split PDF processes the file directly in your browser using client-side code — nothing is uploaded to a server.
  3. Review the result, then click Download to save it to your device.

Frequently Asked Questions

Is Split PDF free to use?

Yes, Split PDF is completely free, with no sign-up, watermark, or software install required.

Is my file safe when I use Split PDF?

Yes. Split PDF runs entirely in your browser using client-side JavaScript, so your file is never uploaded to a server or stored anywhere.

Does Split PDF work on mobile?

Yes, Split PDF works in any modern browser on desktop, phone, or tablet — no app needed.

Is there a file size limit for Split PDF?

Split PDF can comfortably handle everyday file sizes. Very large files may take a little longer since all processing happens on your own device.
