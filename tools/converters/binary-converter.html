How to use Binary Converter

  1. Type a number into the binary field — or into the octal, decimal or hex field instead.
  2. The other three number bases fill in automatically as you type.
  3. Copy whichever result you need.

Frequently Asked Questions

Which number bases can I convert between?

Binary (base 2), octal (base 8), decimal (base 10) and hexadecimal (base 16) — all four fields stay in sync no matter which one you type into.

What if I type an invalid digit for a base?

Binary only accepts 0 and 1 — a digit outside that range (like a stray "2") won't parse correctly, so clear the field and re-enter the value if the other fields look wrong.

Is my data sent to a server?

No. The conversion happens entirely in your browser using standard JavaScript number parsing — nothing is uploaded.

Does it work on mobile?

Yes, it's fully responsive on phones and tablets as well as desktop.
